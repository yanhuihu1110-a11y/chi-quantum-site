# 凯量子 Chi Quantum Website

A static GitHub Pages landing website for Chi Quantum.

## Deploy on GitHub Pages
1. Create a new GitHub repository, e.g. `chi-quantum-site`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/root`, then save.
6. The website will be available at `https://<username>.github.io/chi-quantum-site/`.
